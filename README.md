# 독도를 지켜라

초등학생용 독도 퀴즈 디펜스 게임입니다. dist/index.html을 열거나 ZIP을 모두 풀고 실행합니다. assets 폴더를 함께 유지해 주세요.

## 최신 규칙

- 처음에 쉬움·중간·어려움을 고릅니다. 이어 실제 게임 화면에서 주변을 어둡게 하는 4단계 따라하기를 진행합니다. 문제 정답 → 등대 설치 → 강화는 실제 버튼으로 연습하고, 대포배 그림 설명 후 게임을 시작합니다. 연습 중 전투는 멈추며 연습 점수·포인트·등대는 초기화됩니다.
- 게임·문제·선택지·상태 바를 스크롤 없는 한 화면에 배치합니다.
- 정답: 등대 포인트 +100P, 누적점수 +100점, 독도 에너지 +0.5칸(최대 6). 별이 독도로 날아갑니다. 0.35초 후 다음 문제로 넘어갑니다.
- 오답: 누적점수 −50점, 독도 에너지 −0.5칸(최소 0). 정답을 2초 표시하고 다음 문제로 넘어갑니다. 재선택할 수 없으며 전투는 계속됩니다. 에너지가 0이면 게임 오버입니다.
- 격추: 누적점수 +50점, 등대 포인트 변화 없음.
- 등대 설치 100P, 강화 150P / 200P. 지도 위 위치를 직접 누릅니다. 공격력은 레벨별 8 / 13.5 / 22.5로 이전의 절반입니다. 공격 간격은 유지합니다.
- 독도 에너지 최대 6, 작은 배 충돌 피해 2, 큰 배 4. 해안선에 닿으면 배가 사라집니다.
- 스테이지 적 8 / 12 / 17척. 3단계 17척 중 어려움의 대포배는 10척으로, 순서 1·3·4·6·8·9·11·13·15·17에 분산 출현합니다. 경고는 2초입니다.
- 대포배 체력 315, 공격력 12, 사거리 120, 첫 조준 3초, 발사 간격 8초, 비행 0.8초. 충돌하지 않고 등대를 우선 포격하며 이후 독도를 공격합니다. 독도는 포탄 한 발에도 에너지가 소진됩니다.
- 등대 체력은 16 / 24 / 40으로 대포 2 / 2 / 4발에 파괴됩니다. 강화 시 받은 피해가 유지되고 파괴된 위치는 재설치할 수 있습니다.
- 다음 단계에서 에너지 100%·포인트 0·등대 초기화. 누적점수 유지. 배는 연결망의 최단 경로로 이동합니다.
- 전설 5,000점, 최우수 3,000점, 든든 1,500점, 성장 500점 이상입니다.
- 수동 일시정지는 전투와 문제 전환을 함께 멈춥니다. 다른 탭으로 이동해도 자동 일시정지합니다.

## 학습·검증

문제은행 35개(4지선다 21개, OX 14개). 영유권 근거 5개는 외교부 자료를 참고했습니다: https://dokdo.mofa.go.kr/kor/dokdo/reason.jsp

node verify.cjs는 에너지·점수·오답 2초 전환·3장 설명·3단계 흐름·최단 경로·해안선 접촉·대포배 10척·등대 피해와 파괴·재설치·초기화를 검사합니다. 이번 변경의 브라우저 확인은 로컬 파일 접근 정책으로 수행하지 못했습니다. 이전 가상 난이도 비율은 새 규칙에 적용되지 않습니다.

GitHub 업로드와 온라인 배포는 계정 로그인을 기다리고 있습니다. github-upload 폴더는 최신 배포용 파일입니다.

따라하기는 문제 풀기·등대 설치·강화·대포배의 4단계입니다. 강화와 대포배는 기존 일러스트 설명을 활용합니다. 대포배 설명 그림에는 고정 척수를 적지 않습니다.

적 배 체력을 이전의 0.75배로 조정했습니다. 일반 배는 단계별 24 / 48.75 / 78.75, 큰 배는 일반 배의 2배, 3단계 대포배는 315입니다. 공격력은 유지합니다.

우측 상단 음소거 버튼(🔊/🔇)은 모든 효과음을 켜고 끕니다. 다시하기와 단계 전환 후에도 선택 상태를 유지합니다.

## 난이도 선택 · 최신 규칙

| 난이도 | 정답 회복 | 오답 피해 | 대포 피해 | 3단계 대포배 |
| --- | --- | --- | --- | --- |
| 쉬움 | 1 | 0.5 | 6 | 3척 |
| 중간 | 1 | 1 | 6 | 6척 |
| 어려움 | 0.5 | 0.5 | 12 | 10척 |

어려움은 기존 규칙입니다. 배 체력·등대 체력·점수·전설 5,000점 기준은 공통입니다. 단계가 넘어가거나 재도전해도 선택한 난이도는 유지합니다. 상단 다시하기는 난이도 선택으로 돌아갑니다. 마지막 강화는 200P이며 총 설치·강화 비용은 450P입니다.

클릭 연습은 같은 answer/buyTower 처리를 사용하되 적 이동을 멈추고 시작 전에 연습 상태를 초기화합니다. 연습 정답의 별 효과는 재생됩니다. 브라우저에서 난이도 선택·정답·설치·강화·대포 안내·초기화와 시작을 확인했고, 1366×768·1024×600·800×600·390×844·360×800에서 안내와 목표 위치의 배치를 확인했습니다. 자동 검사에서 세 난이도의 회복·피해·대포 수 및 초기화, 강화 200P를 확인했습니다.

GitHub 변경 파일: index.html, game.js, style.css, 새 onboarding.js. 이 네 파일을 저장소 최상위에 함께 업로드해야 합니다.

튜토리얼 클릭 목표의 테두리와 빛·별이 부드럽게 반짝이며, 마지막 게임 시작 버튼도 강조됩니다. 동작 줄이기 설정에서는 정적인 강조를 사용합니다.

가독성 개선: 선택지 아래 반복 안내를 없애고 새 문제에서는 피드백 칸을 접습니다. 실제 정답·오답 결과와 해설은 표시하며 다음 문제에서 지웁니다. PC 답 버튼 18px/높이68px, 태블릿16px/64px, 휴대폰15px/58px이며 OX는28px입니다. 튜토리얼 정답 별은 1.5초 동안 밝게 날아가고 도착 순간 에너지가 회복됩니다. 도착 후 ‘문제를 맞추면 에너지 회복! 틀리면 소모!’가 떠오르고 다음 버튼을 누르면 등대 설치로 이어집니다. 본 게임 정답 회복 시점은 기존처럼 즉시 적용됩니다. 5가지 화면 크기의 배치와 실제 별 도착을 확인했습니다.

레이아웃 안정화: 게임과 문제 영역의 높이를 화면별로 고정했습니다. 문제 길이·OX/4지선다 전환·정답/오답 피드백이 영역 높이를 바꾸지 않습니다. 해설은 문제 영역 바로 위에 떠 있는 말풍선으로 표시하며 답 버튼이나 문장을 밀어내지 않습니다.

현재 난이도는 음소거 버튼 왼쪽에 표시하며, 게임 오버·최종 승리 팝업의 맨 위에도 표시합니다. 휴대폰 상태 바는 난이도/조작 버튼과 통계가 겹치지 않도록 두 영역으로 배치합니다.
