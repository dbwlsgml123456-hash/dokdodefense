# 독도 방어전

초등 4–6학년용 퀴즈 디펜스 게임입니다. 이전 ‘독도디펜스게임’ 대화와 수정 요청을 반영했습니다.

## 실행

`dist/index.html`을 Chrome 또는 Edge에서 열어 주세요. ZIP을 받았다면 압축을 모두 풀고 `dist` 폴더의 `index.html`을 여세요. 인터넷 없이도 실행되며 온라인 글꼴을 불러오지 못하면 기본 글꼴을 사용합니다.

## 게임 흐름

- 지도 바깥의 제목·설명 영역을 제거해 지도를 위로 넓혔습니다. 지도 안 상단 상태 바에 독도 에너지, 등대 포인트, 누적점수, 스테이지, 남은 적을 표시합니다. 오른쪽 위에는 일시정지(||)/계속하기(▶)와 다시하기(↻) 버튼이 있습니다. 퀴즈와 피드백도 스크롤 없이 한 화면에 표시합니다.
- 첫 화면 중앙에 **독도를 지켜라** 문구와 **게임 시작하기** 버튼이 나옵니다. 각 스테이지의 **게임 시작**을 누르는 순간 적 이동, 문제풀이, 등대 설치가 함께 시작됩니다. 시작 전에는 점수를 모으거나 등대를 설치할 수 없습니다.
- 정답을 맞히면 0.35초의 짧은 확인 표시 뒤 **다음 문제로 자동 전환**됩니다. 이전 문제의 정답 해설은 다음 문제 아래에 남겨 읽을 수 있습니다. 다음 문제 버튼은 없습니다.
- 오답은 정답 선택지를 강조하고 정답·해설을 3초 동안 표시한 뒤 다음 문제로 자동 전환합니다. 모든 선택지가 잠겨 재시도나 중복 감점은 없으며, 그동안 배 이동·등대 공격·설치는 계속됩니다. 수동 일시정지 중에는 전환 시간도 멈춥니다.

## 에너지와 별 효과

독도 에너지 최대치는 6칸이며 처음에는 가득 차 있습니다. 화면에는 백분율과 막대로 표시됩니다.

- 배가 중앙 지점까지 가지 않고, **그려진 섬의 해안선에 선체가 처음 닿는 순간** 에너지가 줄어듭니다. 선체와 해안선에 같은 좌표를 사용하고 이동 구간 전체를 검사하므로 빠른 이동에서도 섬을 통과하지 않습니다. 접촉 지점에 짧은 타격 물결·섬 흔들림·피해량 표시가 나옵니다. 한 배는 한 번만 피해를 줍니다.
- 작은 배 충돌: 에너지 **2칸 감소**. 회복하지 않으면 작은 배가 정확히 3번 닿았을 때 게임 오버입니다.
- 정답: 에너지 **1칸 회복**, 즉 작은 배 한 번의 충돌 피해량의 절반입니다. 최대 에너지를 넘을 수 없습니다.
- 정답을 누른 위치에서 반짝이는 별이 독도로 날아갑니다. 독도에 도착하면 빛이 퍼지며 에너지 회복을 알려 줍니다. 실제 에너지는 정답 순간에 반영되어 회복이 즉시 적용됩니다. 이미 가득 찬 경우에도 별 효과와 ‘에너지 가득!’ 표시가 나옵니다.
- 오답은 에너지를 깎거나 회복하지 않습니다.
- 2단계부터 **큰 배**가 섞여 등장합니다. 큰 배는 같은 단계의 작은 배보다 체력이 정확히 2배이고 충돌 피해도 2배(4칸)입니다. 더 큰 보라색 선체와 ×2 표시로 구분합니다. 큰 배는 작은 배보다 15% 느립니다.
- 일시정지 중에는 적, 자동 문제 전환, 별 효과가 모두 멈춥니다. 다른 탭으로 이동해도 자동 일시정지합니다.

## 등대 포인트와 누적점수

두 값은 독립적입니다.

| 행동 | 등대 포인트 | 누적점수 | 독도 에너지 |
| --- | --- | --- | --- |
| 정답 | +100P | +100점 | +1칸(최대 6칸) |
| 오답 | 변화 없음 | −50점 | 변화 없음 |
| 등대 설치·강화 | 해당 비용 차감 | 변화 없음 | 변화 없음 |
| 적 배 격추(종류 무관) | 변화 없음 | +50점 | 변화 없음 |
| 단계 완료 | 별도 보너스 없음 | 변화 없음 | 변화 없음 |

배 한 척을 격추하면 누적점수만 정확히 50점 올라갑니다. 제거된 배를 다시 계산하지 않아 중복 보상이 없으며, 큰 배도 동일하게 50점입니다. 누적점수는 음수가 될 수도 있습니다. 문제은행의 문제가 다시 나와도 같은 규칙이 적용됩니다.

## 최종 독도 지킴이 등급

승리 또는 게임 오버 시 누적점수, 정답·오답 횟수, 남은 에너지와 함께 등급을 표시합니다.

| 누적점수 | 등급 |
| --- | --- |
| 500점 미만(음수 포함) | 🌱 새싹 독도 지킴이 |
| 500–1,499점 | 🌿 성장하는 독도 지킴이 |
| 1,500–2,999점 | 🛡️ 든든한 독도 지킴이 |
| 3,000–4,499점 | 🏅 최우수 독도 지킴이 |
| 4,500점 이상 | 🏆 전설의 독도 지킴이 |

## 등대와 스테이지

- 지도 위 +를 한 번 누르면 태극기 등대를 즉시 설치합니다(100P). 같은 등대를 다시 누르면 강치 등대(150P), 한 번 더 누르면 강치·괭이갈매기 등대(220P)로 강화합니다.
- 포인트가 부족하면 커서 위에 ‘포인트부족! 문제를 풀어주세요’가 2초간 나타납니다. 터치는 터치 위치, 키보드는 선택한 설치 위치 위에 표시됩니다.
- 1단계: 기존 2단계의 굽은 바닷길 4개·설치 위치 8곳·적 8척. 2단계: 기존 3단계의 사방 바닷길 8개·설치 위치 12곳·적 12척. 3단계: 첨부 스케치처럼 굽이·길이·합류 위치가 서로 다른 비정형 곡선 바닷길입니다. 주요 진입로 6곳, 연결 가지 17개, 설치 위치 17곳, 적 17척입니다. 각 출발점에서 독도까지 거리 합이 가장 짧은 길을 선택합니다. 규칙적인 동심 고리는 없습니다.
- 적은 그려진 길의 꺾이는 지점을 실제로 따라갑니다. 등대는 범위 안의 적을 자동 공격합니다.
- 작은 배의 체력은 단계별 32, 65, 105이고 기본 속도는 14, 18, 22입니다. 2단계는 매 세 번째 배, 3단계는 매 두 번째 배가 큰 배입니다.
- **다음 단계는 독도 에너지 100%, 등대 포인트 0P로 시작**합니다. 모든 등대와 선택 위치도 초기화됩니다. 누적점수와 정답·오답·총 격추 횟수만 이어집니다. 단계 완료 포인트 보너스는 없습니다.
- PC 마우스·태블릿 터치와 Tab/Enter를 지원합니다. 숫자 1–4로 답을 선택하고, 버튼에 초점이 없을 때 Space로 일시정지할 수 있습니다.

## 대포배와 최단 경로 · 최신 변경

바닷길은 옅은 면과 0.8px 가는 선으로 표시합니다. 모든 배는 연결망에서 각 출발점부터 독도까지 최단 경로를 선택합니다. 연결길을 불필요하게 순환하지 않습니다.

3단계 시작 시 ‘대포 배 등장!! 등대 위험!!’가 플레이 시간 2초 표시됩니다. 대포배 3척이 3·9·15번째 순서에 서로 다른 진입로에서 나옵니다. 체력은 420이며 포격 피해는 12입니다. 작은 배보다 25% 느리고 전용 보라색 선체·큰 대포·선원 일러스트로 구분합니다.

사거리 120 안의 등대를 우선 공격하고 없으면 독도 해안선을 조준합니다. 범위 안에서는 멈추며 몸으로 충돌하지 않습니다. 최초 조준 3초·발사 간격 8초·포탄 비행 0.8초입니다. 독도 최대 에너지가 6이므로 포격 한 발에 게임 오버입니다.

등대 에너지는 레벨별 16·24·40이며 피해 없는 상태에서 대포 2·2·4발에 파괴됩니다. 강화 시 기존 피해가 남으며 파괴된 자리는 100P로 재설치할 수 있습니다. 체력 막대·포탄·섬광·연기·파괴 효과를 표시합니다. 일시정지 중 포탄과 경고도 멈추고, 마지막 포탄까지 처리한 뒤 승리합니다.

최신 자동 검사는 최단 거리·경고 2초·3척 분산·420 체력/12 피해·등대 2/2/4발 파괴·강화·재설치·포탄 지연·충돌 금지·일시정지·초기화를 검증합니다. 5가지 화면 크기에서 화면 내 배치를 확인했습니다.

최신 변경: 전설 기준은 사용자 지정 4,500점이며 대포 공격력은 기존 8의 1.5배인 12입니다. 등대 체력은 유지하여 레벨별 2·2·4발에 파괴됩니다. 기존 가상 최고 등급 비율은 현재 기준에 적용되지 않습니다.
