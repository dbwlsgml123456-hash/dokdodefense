# 독도를 지켜라

초등학생용 독도 퀴즈 디펜스 게임입니다. dist/index.html을 열거나 ZIP을 모두 풀고 실행합니다. assets 폴더를 함께 유지해 주세요.

## 최신 규칙

- 처음 게임 시작하기를 누르면 3장 설명이 나옵니다. 다음 버튼으로 넘긴 뒤 마지막 게임 시작하기를 눌러 전투를 시작합니다. 설명 중 배와 타이머는 진행되지 않습니다.
- 게임·문제·선택지·상태 바를 스크롤 없는 한 화면에 배치합니다.
- 정답: 등대 포인트 +100P, 누적점수 +100점, 독도 에너지 +0.5칸(최대 6). 별이 독도로 날아갑니다. 0.35초 후 다음 문제로 넘어갑니다.
- 오답: 누적점수 −50점, 독도 에너지 −0.5칸(최소 0). 정답을 2초 표시하고 다음 문제로 넘어갑니다. 재선택할 수 없으며 전투는 계속됩니다. 에너지가 0이면 게임 오버입니다.
- 격추: 누적점수 +50점, 등대 포인트 변화 없음.
- 등대 설치 100P, 강화 150P / 220P. 지도 위 위치를 직접 누릅니다. 공격력은 레벨별 8 / 13.5 / 22.5로 이전의 절반입니다. 공격 간격은 유지합니다.
- 독도 에너지 최대 6, 작은 배 충돌 피해 2, 큰 배 4. 해안선에 닿으면 배가 사라집니다.
- 스테이지 적 8 / 12 / 17척. 3단계 17척 중 대포배는 10척으로, 순서 1·3·4·6·8·9·11·13·15·17에 분산 출현합니다. 경고는 2초입니다.
- 대포배 체력 420, 공격력 12, 사거리 120, 첫 조준 3초, 발사 간격 8초, 비행 0.8초. 충돌하지 않고 등대를 우선 포격하며 이후 독도를 공격합니다. 독도는 포탄 한 발에도 에너지가 소진됩니다.
- 등대 체력은 16 / 24 / 40으로 대포 2 / 2 / 4발에 파괴됩니다. 강화 시 받은 피해가 유지되고 파괴된 위치는 재설치할 수 있습니다.
- 다음 단계에서 에너지 100%·포인트 0·등대 초기화. 누적점수 유지. 배는 연결망의 최단 경로로 이동합니다.
- 전설 5,000점, 최우수 3,000점, 든든 1,500점, 성장 500점 이상입니다.
- 수동 일시정지는 전투와 문제 전환을 함께 멈춥니다. 다른 탭으로 이동해도 자동 일시정지합니다.

## 학습·검증

문제은행 35개(4지선다 21개, OX 14개). 영유권 근거 5개는 외교부 자료를 참고했습니다: https://dokdo.mofa.go.kr/kor/dokdo/reason.jsp

node verify.cjs는 에너지·점수·오답 2초 전환·3장 설명·3단계 흐름·최단 경로·해안선 접촉·대포배 10척·등대 피해와 파괴·재설치·초기화를 검사합니다. 이번 변경의 브라우저 확인은 로컬 파일 접근 정책으로 수행하지 못했습니다. 이전 가상 난이도 비율은 새 규칙에 적용되지 않습니다.

GitHub 업로드와 온라인 배포는 계정 로그인을 기다리고 있습니다. github-upload 폴더는 최신 배포용 파일입니다.

튜토리얼 그림: 1장은 정답 카드→별→독도 에너지 회복, 2장은 등대 1·2·3레벨과 비용, 3장은 대포배→포탄→등대 위험을 기존 게임 일러스트로 설명합니다. 그림에는 대체 설명을 제공하며, 세로형·높이가 낮은 화면에 별도 배치를 적용합니다.
